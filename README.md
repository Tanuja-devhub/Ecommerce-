# Shopify - Online Shopping System

Shopify is an online shopping system developed as a college project. It provides a simple interface for users to browse products, view product details, add products to their wishlist and cart, and complete the checkout process.

## Features

- User Registration
- User Login
- Product Listing
- Product Search
- Product Categories
- Product Details
- Wishlist
- Shopping Cart
- Update Cart Quantity
- Checkout
- Order Confirmation
- Dark Mode
## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Pages

- `index.html` - Login page
- `register.html` - Registration page
- `home.html` - Home page and product listing
- `product.html` - Product details page
- `cart.html` - Shopping cart
- `checkout.html` - Checkout page
- `order.html` - Order confirmation
